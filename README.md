# Tic-Tac-Toe Game

A clean and interactive web-based Tic-Tac-Toe game built with HTML, CSS, and Vanilla JavaScript. 

## 🎮 Features
- **Two-Player Gameplay:** Play locally against a friend (X and O turns).
- **Winner Detection:** Automatically detects horizontal, vertical, and diagonal winning combinations.
- **Game Controls:** Includes "Reset Game" and "New Game" buttons to easily restart matches.
- **Interactive UI:** Clean interface with hover effects and distinct colors for game elements.

## 🛠️ Tech Stack
- **HTML5:** Structure of the game board and message overlays (`tictac.html`).
- **CSS3:** Styling, flexbox layout, and hover animations (`tic.css`).
- **JavaScript:** Game logic, win validation, and DOM manipulation (`tic.js`).

## 🚀 How to Run
1. Clone this repository or download the files to your local machine.
2. Ensure all three files (`tictac.html`, `tic.css`, and `tic.js`) are located in the same folder.
3. Simply double-click `tictac.html` to open it in any modern web browser and start playing!

## 📂 File Structure
- `tictac.html` - The main HTML file containing the game board layout.
- `tic.css` - The stylesheet providing the visual design, colors, and responsive centering.
- `tic.js` - The script handling player turns, win checking against 8 patterns, and button event listeners.
